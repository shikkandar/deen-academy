# Translating the app's screens into Tamil (Settings → App language)

Repo: the `mobile/` folder of this repository (Expo / React Native, TypeScript). Read `src/lib/i18n.ts` first.

How it works: the English text is the key. In a component: `const t = useT();` (import `{ useT }` from
`@/hooks/use-t`; it follows Settings → Language) and write `t('Search the Library')` instead of the literal. Outside components (plain functions,
constants evaluated at render time): `tr('…')` from `@/lib/i18n`. Values go in placeholders: `t('{n} hadith · {c} chapters', { n, c })`
— never build a sentence by gluing translated pieces. Constants defined at module level (arrays of labels) must be
translated where they are rendered (`t(item.label)`), not at module load.

Then add the Tamil for every new key to the dictionary files in `src/i18n/` (`ta-app.ts` wins over the others), as `'English': 'தமிழ்',`.

Rules
- Translate only the app's own interface text: titles, buttons, labels, hints, empty states, alerts, section headers,
  units ("min", "pages"), relative times ("just now", "{n} min ago").
- Do NOT translate: Arabic text, Quran/hadith/book content, data from JSON assets, the daily reminders and welcome
  messages (`constants/content`, `constants/messages`, the welcome note), names the user enters,
  URLs, console logs, accessibility ids, route names, AsyncStorage keys.
- Keys must be EXACTLY the English shown today, so English looks the same. Keep UPPERCASE section headers as keys and
  give a Tamil header (Tamil has no case).
- Tamil style: simple, natural, respectful app Tamil as Tamil Muslims use it. Prayer names: ஃபஜ்ர், சூரிய உதயம்,
  ளுஹர், அஸர், மஃரிப், இஷா; Azan → பாங்கு; Iqamah → இகாமத்; Namaz/Salah → தொழுகை; Qibla → கிப்லா; Masjid →
  பள்ளிவாசல்; Quran → குர்ஆன்; Surah → ஸூரா; Ayah → ஆயத்; Hadith → ஹதீஸ்; Dua → துஆ; Sunnah → சுன்னத்; Rakat →
  ரக்அத்; Jamaat → ஜமாஅத்; Madhab → மத்ஹப்; Hanafi → ஹனஃபி; Shafi'i → ஷாஃபிஈ. Book names: Sahih al-Bukhari →
  ஸஹீஹ் அல்புகாரி, Sahih Muslim → ஸஹீஹ் முஸ்லிம், Sunan Abu Dawud → ஸுனன் அபூதாவூத், Jami at-Tirmidhi → ஜாமிஉத்
  திர்மிதீ, Sunan an-Nasai → ஸுனன் அந்நஸாயீ, Sunan Ibn Majah → ஸுனன் இப்னுமாஜா, Muwatta Malik → முவத்தா மாலிக்,
  Muntakhab Ahadith → முன்தகப் அஹாதீஸ், Hayatus Sahaba → ஹயாத்துஸ் ஸஹாபா. Keep "Azan", "Android" etc. brand-like words
  where Tamil users keep them.
- Don't change behaviour, layout or styles. Don't touch files outside your list (and your dictionary file).
- Book names coming from data (e.g. `book.name` from hadith-books.json) may be passed through `t(book.name)` and added
  to your dictionary.

When done: run `npx tsc --noEmit` and `npx expo lint` on the repo and fix anything in your files. Reply with one line:
files done, number of keys added.
